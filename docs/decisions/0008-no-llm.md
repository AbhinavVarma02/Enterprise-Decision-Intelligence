# ADR-0008: Deterministic explanations, no LLM adapter

Status: accepted (2026-11-25)

Context. The brief allows an optional local Ollama adapter if it adds demonstrable value.

Decision. Explanations are generated by deterministic templates from computed evidence (gate results, cost deltas, constraint status). No LLM adapter in this version.

Reasons. Template output is verifiable and testable; an LLM adds hallucination risk and a large optional dependency without improving correctness.

Trade-offs. Less fluent prose. Revisit only with an evaluation showing better comprehension at equal accuracy.
